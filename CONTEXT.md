# RowMania

Wir halten für ein paar User Ruder-Challenges fest. Die App ist sehr simpel und nur für ein paar Freunde gebaut.

Es gibt User, Challenges und Sessions.

Eine Challenge hat einen Zeitraum und eine Zielvorgabe (Gesamtdistanz, aus der Summe aller Sessions aller Nutzer zu erreichen).
Jeder User kann an verschiedenen Challenges teilnehmen. Teilgenommen wird, sobald in einer Challenge eine Session gebucht wird.
In einer Session gibt ein Nutzer an "ich habe heute `x`km gerudert". Das Datum kann geändert werden, um Fehleingaben oder vermisste Trainings zu korrigieren

# Startscreen

Ein Login-Formular mit Name und Passwort.

# Challenge-Übersicht

Aktueller Stand der Challenge:
- Gesamtziel erreicht (oder überschritten)
- Beitrag der Teilnehmer am Gesamtziel
- Statistik der Nutzer über den Challengezeitraum (Kurven-/Balkendiagramm)?

# Session-Übersicht

- Möglichkeit, Challenge zu wechseln (die aktuellste ist immer vorausgewählt)
- Möglichkeit, Sessions einzugeben
